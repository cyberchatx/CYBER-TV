# CYBER TV BOX 4.0 – GitHub Pages

Diese Dateien gehören direkt ins Stammverzeichnis des Repositorys `CYBER-TV`.

## Veröffentlichung
1. Im Repository `cyberchatx/CYBER-TV` die vier Dateien `index.html`, `style.css`, `app.js` und `config.js` hochladen.
2. GitHub → Settings → Pages öffnen.
3. Bei Build and deployment `Deploy from a branch` wählen.
4. Branch `main`, Ordner `/ (root)` auswählen und speichern.
5. Danach ist die Seite unter https://cyberchatx.github.io/CYBER-TV/ erreichbar.

## Hinweis
GitHub Pages hostet nur die Weboberfläche. Die ESP32-API unter `/api/status` und `/api/health`, Live-TV-Streamquellen, Aufnahmeserver und echte TV-Steuerung benötigen weiterhin die jeweilige Hardware bzw. Backend-Dienste.
